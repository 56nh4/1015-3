遊戲操作與模型說明

  • 聲音控制：發出較大聲音（如「嗨！」、「跳！」）音量越大跳得越高。
  • 鍵盤備用：可隨時按 空白鍵 或點擊遊戲畫面進行標準跳躍。
  • 障礙閃避：隨機生成低矮與高空障礙，成功跨獲得分。
  • 數據保存：最高紀錄會自動儲存於瀏覽器 LocalStorage 中。

Teachable Machine 整合指南

本系統透過 Web Audio API 即時分析麥克風振幅（RMS），等同於 Teachable Machine 的聲音分類器輸入源。您也可以匯出 TM 音訊模型並嵌入至此 JavaScript 迴圈中進行自訂類別辨識！
